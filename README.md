An original arcade arena game: keep the lanterns lit. The grove is dark — every flame you kindle pushes the night back. Collect glowing embers (max 3 at a time) and carry them to 6 dark lanterns before the 180-second night ends. Dodge the shadow wisps: drifters, lunging darts, huge brutes and weaving wraiths. Grab power-ups — a magnet that pulls embers, swift boots, an aegis shield that blocks one hit — and chase the rare golden ember worth 150 points. Light lanterns in a row without taking a hit to build your streak bonus. Built for the make.fun best-game-01 bounty. Runs offline in a desktop browser from static files, keyboard + mouse, no network.

## Run it

Serve `game/` with any static HTTP server and open `game/index.html`.
